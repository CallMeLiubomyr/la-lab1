## Environment

Use Python 3.14.7 and the shared root `.venv`. See the
[repository setup instructions](../README.md#setup) and
[pinned dependencies](../requirements.txt). Lab 2 uses NumPy, SciPy, Matplotlib,
and NetworkX.

## Execution

Run these notebooks with `lab2/` as the working directory:

- [Core A: Power iteration](lab2-coreA-power_iteration.ipynb)
- [Core B: PageRank](Lab2-CoreB-pagerank.ipynb)

Select the root `.venv` as the kernel, then use **Restart & Run All** and save
the outputs before submission.
